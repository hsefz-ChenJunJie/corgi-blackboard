## 3. 填写规则

- 结果只能填 `通过`、`失败`、`未测`。下表默认全部是 `未测`。
- 会话 ID 在工具栏“诊断”打开的窗口里，“会话：”后面那串字符。
- 失败时按 `feedback-guide.md` 导出反馈包，把包名写进备注。

## 6. 隐私与离线

软件不联网，也没有在线问卷或遥测。日志保存在本机 `%LOCALAPPDATA%\CorgiBlackboard\Logs`，只有测试者在“诊断”窗口手动导出时才会打包。反馈包包含已记录的触点坐标。
