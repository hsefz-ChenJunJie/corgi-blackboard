# 本地教学黑板

面向 Windows 10/11 教学电脑的离线板书、资料展示和批注工具。项目主要服务于本人及少数数学教师，优先考虑触摸屏、实体笔和镜像投屏场景。

项目仍处于测试版本阶段。当前版本首先验证黑板书写、图片资料窗口和课堂操作流程是否顺手；后续功能会按照 [ROADMAP.md](ROADMAP.md) 分阶段推进。

## 第一阶段范围

第一阶段用于验证黑板和图片是否适合课堂使用，目标包括：

- 向四个方向平移的黑板；
- 使用手指、笔或鼠标书写；
- 调整笔色和粗细；
- 局部擦除笔迹；
- 双指移动黑板或滚动图片；
- 使用滚轮和 Shift+滚轮导航；
- 打开多个图片窗口并独立移动、调整大小、最小化、恢复和铺满；
- 在普通窗口和铺满模式下阅读长图并保留批注位置。

PDF、PPT、可靠工作区保存、全局历史、选择变换、截图、桌面悬浮批注和数学工具属于后续阶段或探索方向，当前版本不会把它们标记为已实现。具体顺序见 [ROADMAP.md](ROADMAP.md)。

## 测试与反馈

每个测试版本都附带版本专属课堂清单。实际环境可以按以下顺序反馈：

1. 在清单中记录版本、Windows 版本、屏幕/DPI、投屏方式、触控设备和场景结果。
2. 对失败场景记录操作步骤、预期结果和实际结果。
3. 在软件的诊断界面确认会话 ID。
4. 使用反馈指南导出本地反馈包，并将反馈包与清单一同交给开发者。

测试版本默认在本地保存详细诊断日志，支持查看、保留、清理和显式导出。软件不会自动上传课堂资料、日志或遥测数据。日志中可能包含触点坐标；导出前请确认反馈包内容。

GUI 测试逻辑和实际软件操作测试会随对应版本提供独立测试包及中文说明，供真实环境人工或自动运行。当前开发环境不执行 GUI 测试，因此这些场景的运行结果必须在真实教学环境中记录。

## 架构方向

项目面向 Windows 原生桌面环境，采用 .NET/WPF，并将内容模型、坐标与输入仲裁和 WPF 界面、文件及诊断能力分层。这样后续可以在不改变第一阶段黑板基础的情况下接入：

- PDF/PPT 静态页面和页面批注；
- 工作区保存、迁移和异常恢复；
- 全局撤销与清屏；
- 内容选择、变换和软件内复制；
- 软件截图和桌面悬浮模式；
- 数学图形、坐标系、独立白板和可选离线识别。

所有数据默认本地处理，不要求账户、云服务或联网激活。

## 本地开发

项目的实现代码、测试项目和打包脚本位于开发工作树中。开始开发前请确认已安装与项目锁定版本匹配的 .NET SDK，并在 Windows 环境使用对应的 solution、测试和发布脚本。

本项目明确禁止在开发机执行 GUI、桌面、UI Automation、触控注入、桌面截图或 DPI 操作。可以继续执行与 GUI 无关的编译、纯逻辑测试、文件/日志测试、打包和 CI 检查；不要因 GUI 未测而把这些工作延期。
